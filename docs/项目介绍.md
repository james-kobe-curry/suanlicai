# HOD 算力彩 · 项目介绍

> 算力交易平台（HOD）的支线产品 · 定位：**推广与导流项目**
> 一句话介绍：**用算力 · 猜大奖** —— 用户投入平台算力参与 6 位数字竞猜，每期开奖、80% 返奖、公平可验证。

---

## 一、项目定位

| 维度 | 说明 |
|---|---|
| 是什么 | HOD 算力平台旗下的数字竞猜玩法（彩票式），以算力为筹码 |
| 为什么做 | 盘活闲置算力、提升用户活跃度、为主平台导流 |
| 对用户 | 低门槛、即时反馈的趣味玩法 + 算力激励 |
| 对平台 | 新增流量入口与资产消耗场景，为后续运营活动提供载体 |

## 二、目前已实现的功能

### 1. 核心玩法
- **竞猜码**：每期 6 位数字（000000–999999），支持**单式选号 / 复式投注 / 机选**
- **投入档位（倍投）**：1x / 10x / 100x，投入越大奖金同步放大
- **六档奖级**：一等奖 50%（无人中滚存至下期）· 二等奖 15% · 三等奖 10% · 四等奖 12% · 五等奖 8% · 幸运奖 5%
- **返奖率默认 80%**，每期可由管理员调整；同级多人中奖按投入占比均分

### 2. 活动期次系统
- 管理员**发布活动**：自定义开奖时间、投注截止、**返奖率（每期可调，默认 80%）**、每注基础价
- **自动开奖**：定时调度到点截止投注 → 自动开奖结算；支持管理员手动开奖、取消退款
- **大奖滚存**：一等奖无人中自动滚入下一期

### 3. 开奖公平性（核心卖点）
- 开奖码在**期次发布时即生成**，公开前仅公示 SHA-256 承诺哈希
- 开奖后公布开奖码原文 + 随机盐，**任何人可自行验证** `sha256(开奖码|盐)` 与承诺一致
- 后续计划接入区块链 VRF 随机源，实现链上可验证

### 4. 账户安全体系（完整闭环）
- 注册登录（支持**用户名 / 手机号 / 邮箱**三种方式）
- **强密码策略**（8-64 位、至少 3 类字符、实时强度指示）
- **手机 / 邮箱验证码绑定** + **真实邮件模块**（SMTP，已接入可用）+ 找回密码
- **安全门禁**：未绑定手机/邮箱的用户登录即弹窗提醒，只能浏览、**无法投注/兑换/领算力**
- 封禁/解封、会话管理

### 5. 资产与激励
- 站内 HOD 算力资产 + 全量流水账本（投注/中奖/退款/兑换可追溯）
- 注册赠送、演示算力补给
- **兑换码系统**：管理员批量生成（面额/有效期/批次），用户输入兑换码领取算力

### 6. 管理控制台
- 左侧边栏分区：**期次管理 / 用户管理 / 兑换码管理** + 平台概览统计
- 一键发布期次、立即开奖、取消退款、用户封禁、兑换码生成/禁用

### 7. 视觉与体验
- 科技金融极简风：低饱和深海青蓝主色、**暗色默认 / 浅色可切换**
- 突出数字信息（算力数值/竞猜码/倒计时），全站移动端适配

## 三、业务逻辑（核心流程）

### 用户侧
```
注册/登录 → 绑定手机或邮箱（强制门禁）→ 获得算力（赠送/兑换码）
→ 选择活动期次 → 选号（单式/复式/机选）+ 选择档位 → 确认投注（扣算力）
→ 到点自动开奖 → 中奖奖金自动入账（按奖级瓜分奖池）
```

### 资金模型
```
本期奖池 = 本期销售额 × 该期返奖率（管理员发布期次时设置，1-100%，默认 80%）
         ├─ 一等奖 50%（无人中 → 滚存下期）
         ├─ 二等奖 15% ─┐
         ├─ 三等奖 10%  ├─ 同级按投入占比均分
         ├─ 四等奖 12%  │
         ├─ 五等奖 8%   │
         └─ 幸运奖 5%  ─┘
平台留存 = 本期销售额 × (1 − 该期返奖率)（+均分截断余数）
```

> 说明：**返奖率是运营参数、每期可调**——管理员发布活动时可针对不同场次设置不同返奖率
> （例如新手场 90% 高返奖引流、常规场 80%、活动大促场 85%），灵活匹配运营策略；
> 奖级占比（50/15/10/12/8/5）固定，返奖率只影响奖池总盘子。

### 安全模型
```
关键操作门禁：下注 / 平台绑定 / 领取算力 / 兑换 → 必须已完成手机或邮箱绑定
验证码：5 分钟有效、一次性、60 秒重发冷却、每日限 20 条
密码：8-64 位、至少 3 类字符、不可含用户名；支持验证码找回
```

## 四、技术选型

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | Next.js 16（App Router）+ TypeScript + TailwindCSS v4 | 全栈一体，SSR 展示友好 |

| 工程 | ESLint · Docker 可选 · 独立部署 | 作为 `apps/suanlicai` 独立应用，不侵入主平台 |
