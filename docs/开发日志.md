## Phase 1：立项与基础设施搭建

### 2026-08-15（上午）

**项目立项**
- 确定产品定位：基于 HOD 算力的 6 位数字竞猜平台（类似彩票玩法）
- 核心概念确立：SHA-256 哈希承诺保障开奖公平、80% 默认返奖率、管理员发布期次
- 技术选型决策：
  - Next.js 16 (App Router) + TypeScript
  - Prisma 7 + SQLite（预留 PostgreSQL 切换能力）
  - TailwindCSS v4 自定义设计令牌
  - JWT 认证（jose 库）
  - bcryptjs 密码哈希

**数据模型设计**
- 完成 Prisma Schema 设计，创建 7 张核心表：
  - `User` — 用户账户（含角色、余额、绑定信息）
  - `Round` — 活动期次（含哈希承诺、滚存、返奖率）
  - `Bet` — 投注记录（含竞猜码、档位、中奖等级）
  - `Tx` — 交易流水（含类型、金额、余额快照）
  - `VerifyCode` — 验证码（一次性、限时、限次）
  - `RedeemCode` — 兑换码（批次、状态、防并发）
  - `Setting` — 系统设置（键值对，功能开关）
- 金额统一使用 μHOD（1 HOD = 1,000,000 μHOD），BigInt 存储避免浮点误差

**项目脚手架**
- `npx create-next-app` 初始化项目
- 配置 TailwindCSS v4 设计令牌（明暗双主题 CSS 变量）
- 设置 Prisma 数据源、生成客户端
- 创建基础路由结构

### 2026-08-15（下午）

**核心引擎开发**
- `src/lib/lottery.ts` — 开奖码生成、哈希承诺（commitHash）、校验（verifyHash）、盐值生成（newSalt）、奖级匹配（matchLevel）、复式展开（expandCombos）
- `src/lib/engine.ts` — 结算引擎四核心：
  - `createRound()` — 创建期次、生成开奖码+盐+承诺哈希、吸收历史滚存
  - `placeBets()` — 投注校验、码格式检查、余额扣减、事务写入
  - `settleRound()` — 开奖结算：计算 7 级奖池、匹配中奖、按投入占比均分、保底奖瓜分、滚存传导、用户聚合批量写入
  - `cancelRound()` — 取消期次全额退款
- 奖级体系设计（7 级）：
  - 一等奖 30%（无人中滚存）· 二等奖 15% · 三等奖 10% · 四等奖 18% · 五等奖 12% · 幸运奖 10% · 保底奖 5%

**认证系统**
